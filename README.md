# FlyLog 🚁

[![Language: English](https://img.shields.io/badge/Language-English-blue.svg)](#) [![语言: 简体中文](https://img.shields.io/badge/Language-%E7%AE%80%E4%BD%93%E4%B8%AD%E6%96%87-red.svg)](README-ZH-CN.md) [![Official Download](https://img.shields.io/badge/Download-Official_Site-brightgreen.svg)](https://www.flylog.zone.id)

**FlyLog** is a lightweight, ultra-fast, completely free, and ad-free modern PHP blogging engine. Designed for individual site owners who pursue extreme performance and user experience.

## ✨ Features

- 🚀 **Zero-Dependency**: Written in native PHP, no Composer required. Upload and run.
- 🗄️ **Multi-Database Support**: Native support for MySQL / MariaDB / SQLite / PostgreSQL.
- 🛡️ **Enterprise-Grade Security**: Built-in CSRF protection, native SVG CAPTCHA, brute-force lockout, and XSS filtering.
- 🎨 **Super Customization**: Give the power back to the user! Rename system terms, customize UI layouts, and modify routing rules.
- 📈 **Extreme SEO Optimization**: Auto-generates sitemaps, JSON-LD structured data, and custom TDK (Title, Description, Keywords).
- ♿ **Accessibility (a11y)**: Supports ARIA labels, keyboard navigation, and high-contrast modes.
- 🔌 **Plugin & HOOK System**: Deeply customizable, infinitely extensible ecosystem.

## 🛠️ Quick Start

1. Download the latest version from our [Official Site](https://www.flylog.zone.id).
2. Upload the source code to your web root (e.g., `wwwroot` or `htdocs`).
3. Visit `yourdomain.com/install.php` in your browser and follow the installation steps.
4. **⚠️ Security Note: Immediately delete `install.php` after installation and change the default admin password!**
