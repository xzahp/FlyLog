FlyLog V4.5 更新说明（2026-10-23 晚）
================================================
版本演进：cp -r V4.0 → V4.5（旧版零改动保留）
定位：功能总数冲 200 —— 第七批(151-175 全站 SEO 进阶与流量分发) +
      第八批(176-200 多语言/无障碍/前端体验)，分多轮接力，小周说「继续」即下一轮。
品牌动作（小周要求）：页脚署名统一为「Powered by FlyLog PHP」（学 Z-Blog 的
      "Powered by Z-BlogPHP"：无版本号、无标语，极简），配合「推向大众」去致敬化。

一、品牌与版本
- 页脚只保留：Powered by FlyLog PHP（templates/parts/footer.php，去掉 V 版本号与标语）。
- FLY_VERSION = 4.5（API/后台可见，前台不显示）。
- app.css 注释里的「Z-Blog 式」字样清除（代码层致敬痕迹清零；更新说明 txt 为本地档案，不随前台输出）。

二、第七批第一批（本轮落地 8 项）
- #151 Sitemap 增强：sitemap.php URL 改走 fly_url 规则（自定义伪静态自动适配）、
  补分类页 URL、首页/归档 lastmod=最新文章时间、5000 条上限保护；
  admin/settings.php 新增「SEO 与搜索引擎收录」面板：sitemap 地址 + 百度站长平台 /
  Google Search Console / Bing 站长工具一键提交入口 + OG 封面配置 + 百度推送 token 配置位。
- #153 JSON-LD 增强：fly_tpl_seo 支持多段结构化数据；
  首页输出 WebSite(含 SearchAction 站内搜索) + Blog + BreadcrumbList；
  详情页 BlogPosting(补 image) + BreadcrumbList；归档页 BreadcrumbList。
- #154 canonical：fly_canonical_url() 按当前路径去 query 输出（/?q=x 等动态页 canonical 归一，防重复内容降权）。
- #155 图片 alt 兜底：app.js 对 .post-body 无 alt 图片按文件名清洗填充（SEO + 无障碍）。
- #156 外链 rel=nofollow ugc：fly_process_content() 渲染前给非同站外链补 rel，已有 rel/站内链接不动。
- #161 OG 卡片 + 默认封面：og:image 取文章首图 > 配置 site.og_image > assets/og-cover.png
  （纯 PHP 无 GD 手写 PNG 编码器生成 1200x630 深蓝渐变封面，7594B）。
- #168 HTML 输出压缩：fly_compress_html() 去注释+压空白，bootstrap 以 ob_start 注册；
  script/style/pre/textarea 保护段（JSON-LD 实测压缩后三段全部 VALID）；debug/api/cli/静态构建不启用。
- #172 中英文混排自动加空格：fly_process_content() 内中→英/英→中双向补空格（已有空格不重复）。

三、第八批第一批（本轮落地 7 项）
- #177 ARIA：header 导航 aria-label、搜索表单 role="search" + aria-label、TOC/面包屑已有 aria-label。
- #178 键盘焦点高亮：:focus-visible 统一 2px 品牌色 outline。
- #179 跳过导航直达正文：header.php 输出 .skip-link，index/post 主列 id="fly-main"。
- #180 动画一键关闭：右下「✨ 动画开/已关」浮动按钮，body.no-anim 全局去过渡动画，
  localStorage 记忆（照顾晕动症/前庭敏感用户）。
- #183 移动端点击区域 >=44px：.btn/.back-top/.fx-toggle/.speak-btn/搜索框按钮 min-height:44px。
- #187 纯文字模式：?text=1 不加载任何 CSS/JS/图片，内联极简样式，省流量秒开。
- #191 语音朗读：文章页「🔊 朗读」按钮，Web Speech API 朗读正文（zh-CN），再点停止；不支持则隐藏。
