====================================
   FlyLog V1.01 更新说明
====================================
日期：2026-10-21
基线：V1.0（2026-10-20 交付，原版保留在 FlyLog\V1.0\，未动一个字节）
性质：修订版（patch）——修 1 个 bug + 4 项安全加固 + 2 项体验，不改架构、不换风格

------------------------------------
一、修复
------------------------------------
1. 列表页摘要回退失效（index.php）
   问题：V1.0 的列表 SQL 只查了 id/title/summary/category/created_at，
        没查 content 列，但摘要回退逻辑却读 $row['content']。
        老文章（summary 为空）会触发 PHP 警告，且摘要显示空白。
   修复：SELECT 补上 content 列；回退读取加 ?? '' 双保险。

------------------------------------
二、安全加固
------------------------------------
2. 留言重定向开放式重定向防护（post.php）
   问题：留言成功后 header('Location: ' . $_SERVER['REQUEST_URI'])，
        REQUEST_URI 可被伪造成 //evil.com 或 http://evil.com，把用户弹到外站。
   修复：仅放行以 / 开头的站内路径（拒掉 //、\、:// 三种花招），否则回退 index.php。

3. 后台登录防爆破（admin/login.php）
   新增：同一会话连续输错 5 次密码 → 锁定 5 分钟；
        锁定期间即使密码正确也拦截；期满自动解锁并重新计数；登录成功立即清零。

4. 会话 cookie 加固（config.php + admin 全部页面）
   新增 fly_session_cookie_params()：HttpOnly（防 XSS 窃取 cookie）
   + SameSite=Lax（防 CSRF）。登录/后台/退出全站统一参数；
   logout.php 改用数组形式 setcookie，确保 cookie 被彻底清除。
   注意：secure 固定为 false——站点是 HTTP 部署，误开 secure 会导致 cookie 不发、登录不上。

5. 服务端长度校验（post.php / admin/post.php）
   问题：HTML maxlength 只是客户端限制，直接 POST 可绕过。
   新增：留言昵称 ≤100 字、内容 ≤2000 字；文章标题 ≤255 字、分类 ≤100 字，
        超限友好报错（配套新增 fly_len() 助手，无 mbstring 扩展时退化为字节数）。

------------------------------------
三、体验
------------------------------------
6. 🚁 emoji favicon：前台/后台/登录页全部加上，数据 URI 内联零请求，
   浏览器标签页终于有图标了，顺手消灭 favicon 404。
7. 版本号：config.php 新增 FLYLOG_VERSION 常量，页脚显示
   "Powered by FlyLog V1.01"，以后每个版本一眼可辨。
