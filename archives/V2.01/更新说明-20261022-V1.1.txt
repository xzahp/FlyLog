====================================
   FlyLog V1.1 更新说明
   2026-10-22 · 小航 🚁
====================================

升级方式：整份 cp -r V1.01 → V1.1 后修改，V1.0 / V1.01 原样保留、零改动。
版本号规则：本次为中等步升级 +0.1（V1.01 → V1.1）。

------------------------------------
一、登录与账号安全加强
------------------------------------
1. 防爆破升级：IP + 数据库级（login_attempts 表）
   - 旧版按会话计数，清 cookie 即可绕过；新版按来访 IP 落库，
     同一 IP 连错 5 次锁定 5 分钟，清 cookie / 换浏览器都没用。
   - 锁定期满自动解锁重新计数；登录成功立即清除该 IP 失败记录。
2. 新增登录日志（admin_logs 表）
   - 每次登录尝试（成功/失败）都记录：账号、IP、结果、时间。
   - 后台「登录日志」页可查最近 100 条、看近 24 小时失败次数、一键清空。
3. 新增「修改密码」页（admin/password.php）
   - 验证旧密码 → 设新密码（至少 8 位、两次输入一致、不能与旧密码相同）。
   - 密码一律 password_hash 哈希存储。
4. 安装即注册管理员
   - install.php 新增可选表单：自定义管理员账号 + 密码（至少 8 位、带确认）。
   - 留空直接安装则仍用默认 admin / 123456。

------------------------------------
二、后台功能扩充
------------------------------------
1. 仪表盘（admin/index.php 重做）
   - 统计卡片：文章总数 / 待审核留言 / 留言总数 / 分类数 / 总阅读量 / 近 24h 登录失败。
   - 快捷入口：写新文章、文章管理、留言审核（带待审核角标）、登录日志、修改密码。
   - 最近文章 5 篇 + 待审核留言预览。
2. 文章管理独立成页（admin/posts.php）
   - 原后台首页的文章列表迁来，新增按标题搜索，列表增加阅读量列。
3. 留言审核（admin/comments.php，全新）
   - V1.1 起前台留言「先审后发」：提交后 status=0 待审核，
     博主通过后才对外显示；支持 通过 / 撤下 / 删除 / 一键通过全部。
   - 按 全部 / 待审核 / 已通过 筛选；留言所属文章被删也能管理（LEFT JOIN）。
4. 全后台统一顶部导航：仪表盘 / 文章管理 / 留言审核 / 登录日志 / 修改密码。

------------------------------------
三、前台功能扩充
------------------------------------
1. 全站搜索（index.php?q=关键词）
   - 匹配标题 / 摘要 / 正文；侧边栏新增搜索框；命中词黄色高亮（已防 XSS）。
2. 文章阅读量
   - posts 表新增 views 列；进详情页 +1，同一会话重复刷新不重复计数。
   - 首页列表、详情页 meta、后台文章管理、仪表盘均可看阅读量。
3. 文章归档页（archive.php，伪静态 /archive）
   - 按年月分组列出全部文章 + 全站统计（文章数 / 留言数 / 分类数）。
4. RSS 订阅（feed.php，伪静态 /feed）
   - 输出 RSS 2.0，最新 10 篇（标题 / 链接 / 摘要 / 发布时间），阅读器可直接订阅。
5. 导航调整：顶栏与侧边栏新增「归档」「RSS 订阅」入口。

------------------------------------
四、数据库变化（旧库平滑升级）
------------------------------------
- 新增表：login_attempts（登录防爆破）、admin_logs（登录日志）。
- posts 表新增 views 列（INT UNSIGNED 默认 0）。
- comments 表新增 status 列（0 待审核 / 1 已通过，默认 1）。
  旧库补列时历史留言默认视为已通过，不会凭空消失。
- 升级方法：旧数据库再跑一次 install.php 即可自动补表补列，不丢数据。

------------------------------------

  正确返回友好「数据库连接失败」提示页（符合既有测试约定）。
- .htaccess 新增 /archive、/feed 两条伪静态规则（位置无关，随文件夹部署）。

------------------------------------
- V1.1 已实际部署到 www.flylog.zone.id（青云/轻云虚拟主机，PHP 8.0 +
  Apache + MySQL）并全站联调通过：伪静态 /post/*.html、/archive、/feed，
  搜索高亮、阅读量、留言审核全流程、登录日志、仪表盘均正常。
- 部署中修复 2 个线上才暴露的问题（已改进 V1.1 源码）：
  ① install.php：原「无条件 CREATE DATABASE」在虚拟主机（账号无全局
     建库权、库由面板预建）会误报 access denied。改为「先 select_db，
     选不上再 CREATE DATABASE」，对共享主机更稳健。
  ② feed.php：在开启 short_open_tag 的主机上 500。根因是某行 // 注释里
     含 PHP 结束标记字样，提前闭合了 PHP 模式。已清除注释中的标记字样，
     XML 声明统一用 echo 输出。
- 新增验证约定：虚拟主机常开 short_open_tag，本地 php -l 测不出，须用
  `php -d short_open_tag=1 -l` 全量复测（V1.1 已 15/15 通过）。
