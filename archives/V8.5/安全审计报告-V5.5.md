## 3. P0 / P1 明细与修复

### P0-1 安装器无「已安装」守卫（install.php）
- **风险**：已安装站点仍可访问 install.php 进入安装流程，可重新创建管理员账号 → 后台接管。
- **修复**：写入 `install.lock`；进入安装流程前检测锁文件，已锁则 `http_response_code(403)` 并终止。

### P0-2 配置回写未转义导致任意 PHP 写入（install.php）
- **风险**：`fly_install_write_config` 以字符串拼接生成 config.php，若用户输入含 `?>` 闭合 + 恶意代码，可 getshell。
- **修复**：改用 `preg_replace_callback` 把配置值经 `var_export()` 安全序列化后再回写，密码等字符串走 `var_export`（自动加引号/转义），杜绝标签闭合注入。

### P0-3 安装器/配置入口可重复触发（链式 RCE 前置）
- **风险**：DDL 与建表语句含用户输入拼接；admins 表非空时仍可走注册分支。
- **修复**：DDL 标识符走白名单；`admins` 表非空则拒绝「注册管理员」分支。

### P1-1 开放重定向（functions.php · fly_redirect）
- **修复**：仅允许同 host（解析后比对）重定向，否则按站内路径处理。

### P1-2 响应头 CRLF 注入（file.php · Content-Disposition）
- **修复**：拼头前 `str_replace` 剥离 `\r\n`，附件文件名无法注入额外响应头。

### P1-3 模板本地文件包含 LFI（template.php · fly_render）
- **修复**：模板路径 `realpath` 后必须落在 `FLY_TPL` 目录内，越界返回「非法模板路径」标记。

### P1-4 JSON-LD 存储型 XSS（template.php · fly_tpl_seo）
- **修复**：`json_encode` 增加 `JSON_HEX_TAG|JSON_HEX_AMP|JSON_HEX_APOS|JSON_HEX_QUOT`，`</script>` 被转义为 `\u003C/script\u003E`，无法闭合 script 标签。

### P1-5 草稿/定时文章越权公开（post.php / base.php::find）
- **修复**：`find()` 统一过滤 `is_draft=0 AND (publish_at IS NULL OR publish_at <= CURRENT_TIMESTAMP)`；`post.php` 改回 `find($id)`（不再 `withDraft`）；`incrementViews` 同步过滤。

## 4. P2 / P3 代表性加固
- **security.php**：`fly_force_https` 顺序修正；CSP 白名单加入 cdnjs.cloudflare.com（highlight.js CDN）；`fly_mask_ip` 拼写 `FILTER_VAGIDATE_IP`→`FILTER_VALIDATE_IP`；`fly_password_hash` 优先 Argon2id。
- **functions.php**：`fly_e` 加 `ENT_QUOTES`；`fly_json` 加 `JSON_PARTIAL_OUTPUT_ON_ERROR` 且编码失败返 500；`fly_csrf_check` 强化；`fly_build_toc` 锚点 id 白名单；`fly_process_content` 外链加 `rel=nofollow ugc`；`fly_notify` URL 校验 + `CURLOPT_SSL_VERIFYPEER` 默认开启。
- **db.php**：新增 `fly_ident` 标识符白名单；`FlyQuery` 的 `select/where/whereIn/order` 全部经 `fly_ident` 包裹；`order()` 改为追加语义（修掉置顶丢失）；`insert/update/delete` 表名白名单；DSN 连接失败优雅处理；`fly_schema` 四库 DDL 修正。
- **cache.php**：`serialize`→`json_encode/decode`（防缓存反序列化 RCE）；Redis 异常降级；日志路径净化；原子写。
- **router.php**：`fly_static_name` 拒绝 `../` 与路径分隔符；`fly_static_build/serve` 加 `realpath` containment。
- **base.php**：会员注册走 `fly_password_hash`；留言默认 `status=0`（待审）；删留言清理孤儿。
- **bootstrap.php**：内存解析修正；`register_shutdown_function` 扩记 Warning/Notice；会话加固；HTTPS/安全头/异常处理器顺序；JSON 压缩旁路。

## 6. 部署与兼容性结论
- 部署：上传 V5.5 整份内容至网站根目录；**绝不覆盖线上 config.php**，download.php/downloads 暂不部署；install.php 保留（已加锁）。
- 全量 lint：52/52 个 PHP 文件 `php -d short_open_tag=1 -l` 通过。
- 数据库兼容：V5.5 代码引用的 `is_pinned/is_draft/publish_at` 等均自 V2.0 起存在于线上库；V5.0/V5.5 新功能走 `options` 键值表（无新增列），对线上 MySQL 结构兼容，`fly_schema` 的 `CREATE TABLE IF NOT EXISTS` 对已有表为 no-op。
