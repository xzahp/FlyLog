FlyLog V6.5 更新说明（Z-Blog 风格登录体验版）
发布日期：2026-10-25
包名：FlyLog-V6.5.zip

【版本定位】
V6.5 是一次聚焦「后台第一印象」的体验升级。后台登录页是每位站长每天打开
FlyLog 的第一个界面，此前的版本它只是一张朴素的表单，功能够用但谈不上
好看、也谈不上安心。V6.5 参考了 Z-Blog 后台登录页的经典双栏布局，把
「品牌展示」与「登录表单」放在同一屏，并补齐了图形验证码、记住我、
密码可见切换、登录失败锁定提示、忘记密码引导等一整套登录环节该有的
能力。全部代码继续坚持零第三方依赖：验证码不依赖 GD 库（使用原生 SVG
绘制），样式是一个独立的 login.css，老服务器上传即可用。

【全新登录界面（仿 Z-Blog 双栏布局）】
一、左右双栏卡片。左侧为品牌区：FlyLog 纸飞机 Logo、系统名称、版本号、
    三行特性简介与装饰性航迹虚线；右侧为登录表单区。窄屏（手机）自动
    折叠为单栏，品牌区收成顶栏，不占纵向空间。
二、图形验证码。新增 admin/captcha.php，用纯 PHP 生成 4 位 SVG 验证码：
    随机扭曲字符 + 干扰线 + 干扰点，答案存 session 并 5 分钟过期、用过
    即作废。无 GD 扩展的服务器照样出图。可在 config.php 的
    features.admin_captcha 设为 false 一键关闭。
三、记住我（30 天）。勾选后登录成功会写入一条 HttpOnly 的独立 Cookie，
    令牌为 64 位随机十六进制并加盐哈希入库（admins 表新增
    remember_token / remember_expire 两列，老库由 fly_db_migrate()
    自动补齐，无需手工改库）。Cookie 与令牌双向校验，改密码后所有
    旧「记住我」立即失效。
四、密码可见切换。密码框右侧小眼睛图标，点击在明文/密文间切换，避免
    大小写混排密码输错锁门。
五、失败友好提示与锁定倒计时。连续输错 5 次锁定本 IP 1 小时，登录页不再
    只说"错误"，而是显示"还需等待 X 小时 / X 分钟"的实时倒计时；验证码
    错误会自动刷新验证码图。提示文案不区分"用户不存在"与"密码错误"，
    防止账号枚举。
六、忘记密码引导。点击"忘记密码"会展开内嵌指引：用 FTP 查看/编辑
    datadir 下的说明文件或使用 CLI 重置密码，附两种方式的具体命令，
    不再把站长晾在登录页。
七、细节体验。回车直接提交；登录成功后台会话 ID 强制重建
    （session_regenerate_id），直达后台首页；页脚保留"返回网站首页"
    与"Powered by FlyLog"。

【登出与安全强化】
八、logout.php 重写：登出时同步吊销「记住我」令牌（数据库置空 +
    Cookie 置过期）并完整销毁会话，杜绝"登出后旧 Cookie 仍然
    可用"的隐患。

【数据库与兼容性】
九、fly_db_migrate() 迁移计划新增 admins 表 remember_token（VARCHAR(64)
    可空）与 remember_expire（DATETIME 可空）两列，SQLite/MySQL/
    MariaDB/PgSQL 四种驱动均幂等可重入，老站升级零手工操作。
十、PHP 5.6+ 兼容：全部新代码使用 array() 语法与 PHP 5 兼容写法，
    不引入任何新扩展依赖。

【升级方式】
1. 备份站点文件与数据库；
2. 将 V6.5 包覆盖上传（config.php、datadir/ 不会被包内同名文件
   覆盖，请勿把本地配置传上服务器）；
3. 访问任意页面，fly_db_migrate() 自动完成 admins 表补列；
4. 使用原账号密码登录后台，即可看到新版登录页。
