# FlyLog 🚁

[![Language: English](https://img.shields.io/badge/Language-English-blue.svg)](README.md) [![语言: 简体中文](https://img.shields.io/badge/Language-%E7%AE%80%E4%BD%93%E4%B8%AD%E6%96%87-red.svg)](#) [![官方下载](https://img.shields.io/badge/%E5%AE%98%E6%96%B9%E4%B8%8B%E8%BD%BD-%E7%82%B9%E5%87%BB%E5%89%8D%E5%BE%80-brightgreen.svg)](https://www.flylog.zone.id)

**FlyLog** 是一款轻量、极速、完全免费且无广告的现代 PHP 博客引擎。专为追求极致性能和用户体验的个人站长打造。

## ✨ 核心特性

- 🚀 **零依赖开箱即用**：原生 PHP 编写，无需安装 Composer，上传即用。
- 🗄️ **多数据库支持**：原生支持 MySQL / MariaDB / SQLite / PostgreSQL（SQLite 模式下连数据库都不用配）。
- 🛡️ **企业级安全防护**：内置 CSRF 防护、原生 SVG 图形验证码、防暴力破解锁定、XSS 过滤。
- 🎨 **超级自定义权**：把修改权交还给用户！全站命名、UI 布局、路由规则均可自定义。
- 📈 **极致的 SEO 优化**：自动生成 Sitemap、JSON-LD 结构化数据、自定义 TDK。
- ♿ **无障碍设计**：支持 ARIA 标签、键盘导航、高对比度模式。
- 🔌 **插件 HOOK 机制**：支持深度定制，生态无限扩展。

## 🛠️ 极简安装步骤

1. 前往 [FlyLog 官方网站](https://www.flylog.zone.id) 下载最新版本的安装包。
2. 将源码上传至你的虚拟主机或服务器根目录（`wwwroot` 或 `htdocs`）。
3. 浏览器访问 `你的域名/install.php`，按提示完成数据库配置。
4. **⚠️ 安全提示：安装完成后，请立刻删除 `install.php`，并在后台修改默认管理员密码！**
